# Open Source Strategy

AgentKick should be open source because the core artifact is repo trust.

Developers will only adopt an AI workflow operating system if they can inspect what it writes, understand how it scores, and keep working without a hosted service.

## Open Source Core

Keep open:

- CLI
- templates
- official core packs
- memory schemas
- context schemas
- Doctor rules
- scoring model
- plugin SDK
- GitHub Action

Why:

- trust
- adoption
- ecosystem
- community packs
- credibility with serious developers

## Monetization Without Breaking Trust

Do not monetize basic local use.

Premium should add team coordination:

- hosted Doctor dashboards
- organization policies
- private plugin registry
- signed plugin approval
- cross-repo readiness reporting
- workflow analytics
- team memory review
- enterprise compliance exports

## Community Flywheel

1. Developers run `npx agentkick init`.
2. Repo gets better agent files.
3. Doctor finds workflow issues.
4. Developers share score screenshots and before/after diffs.
5. Teams standardize AgentKick in CI.
6. Contributors add templates and packs.

## GitHub Strategy

Use GitHub as the primary adoption channel:

- excellent README
- short demo GIF
- real before/after examples
- issue templates
- good first issues
- examples folder
- GitHub Action badge
- release notes with CLI screenshots

## Contribution Strategy

Accept contributions for:

- templates
- packs
- Doctor checks
- docs
- fixture tests
- platform integrations

Be strict on:

- vague AI claims
- retrieval features
- unsafe writes
- noisy Doctor rules
- generated file churn

## License

Keep permissive licensing for core CLI.

Enterprise value should come from hosted coordination and governance, not locking local workflows.

## Launch Checklist

- clean README
- npm package
- demo video
- examples
- docs index
- GitHub Action example
- issue templates
- roadmap
- contributing guide
- clear product boundary

## Community Position

AgentKick is for developers who already use AI coding tools and want the repo to stop depending on giant chats and repeated instructions.
