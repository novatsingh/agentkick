# Virality Strategy

AgentKick should grow through visible repo improvements and shareable diagnostics.

The product is strongest when developers can see before and after.

## Viral Hooks

### Doctor Score

Shareable:

```text
AgentKick Doctor
AI readiness: 84/100
Token waste risk: 32/100
```

Use:

- README badge
- PR comment
- launch screenshots

### Before/After Repo Root

Show:

- messy root with no memory
- clean AgentKick docs and workflow files
- Doctor score improvement

### Context Waste Findings

Memorable labels:

- Context Furnace
- Memory Void
- Workflow Fog
- Thread Anchor
- Contract Shadow

These make abstract AI workflow problems easy to discuss.

### Agent-Ready Badge

```markdown
![AgentKick Ready](https://img.shields.io/badge/AgentKick-ready-brightgreen)
```

Future:

- dynamic badge from GitHub Action

## Launch Story

Headline:

```text
Stop starting every AI coding session from zero.
```

Demo:

1. Run `npx agentkick init`.
2. Show generated memory and agent files.
3. Run `agentkick doctor`.
4. Show context waste finding.
5. Run `agentkick fix --safe`.
6. Show improved readiness.

## Developer Onboarding Flow

1. See README.
2. Run `npx agentkick init`.
3. Inspect diff.
4. Run `agentkick doctor`.
5. Add one pack.
6. Commit generated files.
7. Use Codex/Cursor/Claude with less explanation.
