# Differentiation

AgentKick is differentiated by workflow structure, not code retrieval.

## Core Distinction

```text
Repository understanding tools help find and explain code.
AgentKick makes AI work around the repository structured, repeatable, and persistent.
```

## AgentKick Versus AI Coding Wrappers

AI wrappers:

- put a chat UI over a model
- rely on prompt quality
- often keep memory in the conversation

AgentKick:

- writes repo-native memory
- standardizes agent operating files
- scores AI workflow readiness
- scopes execution
- survives thread reset

## AgentKick Versus Retrieval Tools

Retrieval tools:

- search code
- index code
- find relevant snippets
- answer "where is this?"

AgentKick:

- prepares task context
- defines workflow state
- preserves project memory
- defines agent rules
- answers "how should agents work here?"

## AgentKick Versus Linters

Linters:

- enforce code style or correctness rules

AgentKick Doctor:

- detects AI workflow risks
- finds context waste
- checks memory gaps
- checks execution isolation
- checks workflow continuity

## AgentKick Versus Project Templates

Project templates:

- create starter files

AgentKick:

- creates starter files
- upgrades existing repos
- adds agent memory
- adds workflow packs
- audits readiness
- grows with the repo

## AgentKick Versus Internal Docs

Docs:

- often drift
- are written for humans
- rarely define agent execution rules

AgentKick memory:

- has file conventions
- has update lifecycle
- has Doctor validation
- is optimized for coding agents and humans

## Defensible Surface

AgentKick can become hard to replace through:

- memory conventions
- workflow packs
- Doctor scoring
- task state files
- plugin ecosystem
- GitHub integration
- team policies
- cross-agent compatibility

## The Moat

The moat is not proprietary AI.

The moat is becoming the standard repo-native workflow layer for AI-assisted software development.

## Non-Differentiators

Avoid competing on:

- model quality
- semantic search
- vector index speed
- "AI magic"
- generic code generation

## Differentiation Statement

AgentKick does not try to understand your repo better than every tool.

It makes your repo easier for every coding agent to operate inside.
