# Market Positioning

## Final Positioning

```text
AgentKick is the workflow operating system for AI-native software development.
```

It structures how coding agents understand repos, manage context, preserve memory, and execute work.

## What AgentKick Is Against

AgentKick is against:

- chaotic vibe coding
- context overflow
- giant AI chats
- temporary chat memory
- workflow fragmentation
- AI repo confusion
- repeated project explanations
- unscoped agent edits
- unverifiable agent output

## What AgentKick Is Not Against

AgentKick is not positioned against:

- retrieval engines
- semantic search tools
- indexing systems
- code graph tools

Those tools help understand code. AgentKick structures workflows around code.

## Critical Differentiation

```text
Sverklo/codegraph-rust understand repositories.
AgentKick structures AI workflows around repositories.
```

This is the central distinction.

AgentKick does not need to out-search search tools. It should make the repo operationally ready for agents after those tools, IDEs, humans, or agents find the relevant code.
